# AttackInfo Payload / Damage / Element / ActiveStatus 字段词典

状态：默认可用


## 文件与上下文

| 项 | 目标核验 | 边界 |
| --- | ---: | --- |
| 全 PVF `.atk` 扩展名文件 | 需在当前目标 PVF 中只读确认 | 扩展名不等于所有文件都已闭合到 owner 或 hitbox。 |
| `passiveobject/` `.atk` 文件 | 需在当前目标 PVF 中只读确认 | 本词典的统计桶；不代表 character、monster、AI character 等全域已穷尽。 |
| `[ACTIVE STATUS]` 大写 | 需在当前目标 PVF 中只读确认 | 样本是 `.act` 行为上下文，不并入 `.atk [active status]` 结论。 |

## 基础 payload

| 字段 / 块 | 目标核验 | 已观察列形 / token | 边界 |
| --- | ---: | --- | --- |
| `[attack type]` | 需在当前目标 PVF 中只读确认 | 块内可见 `[physic]`、`[magic]`。 | 不证明最终防御结算。 |
| `[attack enemy]` | 需在当前目标 PVF 中只读确认 | 单数值行。 | 不证明实机敌我判定。 |
| `[attack friend]` | 需在当前目标 PVF 中只读确认 | 单数值行。 | 不证明友方命中或治疗规则。 |
| `[damage reaction]` | 需在当前目标 PVF 中只读确认 | 样本中可含 `[damage]`、`[down]`、`[push aside]`、`[lift up]`、`[knuck back]`。 | 不证明卡肉、击退、浮空或倒地实机表现。 |
| `[hit wav]` | 需在当前目标 PVF 中只读确认 | 反引号声音 token。 | 不证明客户端音频资源存在或实际播放。 |
| `[hit info]` | 需在当前目标 PVF 中只读确认 | 可含 `[blow]`、`[cut]`、`[blood]`、`[no blood]`、`[noblood]`。 | 不证明血效、切割表现或 UI 正常。 |

| --- | ---: | --- | --- |

| PVP `[damage reaction]` | 需在当前目标 PVF 中只读确认 | 可覆盖 `[damage]`、`[none]`、`[down]` 等。 | 不证明击退、浮空、硬直实机结果。 |

## 字段组合核验边界

- 分别核验攻击信息对象、伤害倍率、固伤、武器伤害、元素、攻击类型、击退/浮空和异常状态。
- 状态行可能同时涉及类型、概率、等级、时间和伤害；不能凭列位或 API 参数名称直接定性。

## 未证明事项

- 不证明伤害公式、最终伤害、独立攻击力、技攻、附加伤害或异常伤害结算。
- 不证明元素强化、抗性、属性攻击、无属性或多属性的最终生效。
- 不证明异常状态概率、等级、持续、伤害、抗性、免疫或 PVP 修正。
- 不证明 `.atk` 能被 owner 实际触发，也不证明 `.ani` 攻击框命中。
