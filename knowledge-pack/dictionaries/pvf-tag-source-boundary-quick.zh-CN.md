# PVF Tag 可信层快速边界

状态：需验证

用途：回答 Section / tag 含义、字段注释冲突和 registry 提示问题。Workbench 已内置去除数据库、作者、来源路径和维护记录后的紧凑事实。

## 固定层级

- `community`：社区解释候选，可帮助理解字段，但不是官方定义。
- `official-original`：官方原文层；翻译必须独立记录，不能覆盖或伪装成原文。
- `tool-extension`：工具扩展层，不能计入官方原文。
- `registry-hint`：只负责提示可能的 `.lst`；拼写修正仍是候选，必须回到目标 PVF 验证。
- `target-readback`：当前目标 PVF 的原文与 registry 解析，任务结论必须落到这一层。

内置目录和目标观察都是定位索引。搜索 0 命中不证明 tag 不存在；作结论或写入前仍要读回目标文件和同目录最近邻样本。

## 查询顺序

1. 规范化查询 tag，同时保留各层原始拼写。
2. 并列显示社区解释、官方原文、翻译状态和工具扩展；冲突不静默合并。
3. 对目标 PVF 做局部 observation，最多取少量最近邻样本并绑定完整 PVF SHA。
4. 涉及数字 ID 时按父块上下文解析正确 `.lst`；registry 提示不能代替解析。
5. 静态样本不能证明客户端 UI、服务端采用、运行时效果或跨版本兼容。

维护期目录构建见 `docs/TAG-KNOWLEDGE-CATALOG.zh-CN.md`；普通任务不需要阅读或配置它。
