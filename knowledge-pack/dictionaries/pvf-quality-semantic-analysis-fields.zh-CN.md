# PVF 质量审计与语义分析词典

状态：默认可用

## 质量审计类别

| 类别 | 静态检查 | 边界 |
| --- | --- | --- |
| registry path | `.lst` 中登记的相对路径是否存在、能否读取、是否多义。 | 文件存在不证明运行时加载；未登记文件不等于可删除孤儿。 |
| LST duplicate | 同一个 `.lst` 内编号是否重复；同时保留重复路径和重复编号两种报告。 | 不自动保留“最后一条”或静默去重。 |
| cross-registry intersection | `equipment.lst` 与 `stackable.lst` 是否出现同号 ID。 | 同号是冲突候选，需结合目标客户端解析与引用上下文；不能按数字范围猜类型。 |
| equipment layer | `.equ` 声明的职业 / 动作 layer 候选路径是否存在。 | 路径闭合不证明动作、时装层或客户端资源正常。 |
| stack limit duplicate | 单个 `.stk` 是否重复出现 `[stack limit]`。 | 报告父块和原始位置，不自动删其中一块。 |
| dungeon map index | `.dgn` 中 map index 是否通过 `map/map.lst` 闭合。 | 同目录相似文件名不能替代 registry。 |
| map entity registry | `.map` 的 monster、NPC、APC / AIC 是否按各自 registry 闭合。 | 三类 ID 不共用 registry；裸数字不跨父块解释。 |
| SQR definitions | 同一分析范围是否有重复函数定义、显式调用是否找不到可见定义。 | include、动态调用、运行时注入会产生未知；0 命中不证明安全。 |
| ACT structure | 标签是否成对、引用路径是否闭合、是否出现常见拼写异常。 | 源拼写保留；只能提出候选修正，不能静默改字。 |

## 语义对比集合

| 集合 | 含义 |
| --- | --- |
| only-left | 需在当前目标 PVF 中只读确认 |
| only-right | 只在对照 / 右侧 PVF 出现的规范化路径。 |
| common-equal | 两侧路径相同，解析后的语义内容相同。 |
| common-different | 两侧路径相同，但解析后的语义内容不同。 |
| unresolved | 任一侧读取、StringTable 解析、编码或结构化失败，不能归入相同 / 不同。 |

“语义相同”表示在声明的解析方式下相同，不表示裸字节、压缩数据、格式、注释或运行行为相同。大小相同也不代表内容相同。

## 结果集运算

| 操作 | 含义 |
| --- | --- |
| 覆盖 | 用新查询结果替换当前工作集。 |
| 并集 | 保留当前与新查询命中的全部唯一路径。 |
| 交集 | 只保留两次查询都命中的路径。 |
| Match | 在当前工作集内保留满足二次条件的文件。 |
| Remove | 从当前工作集剔除满足二次条件的文件。 |

查询模式可以是路径、字符串、数字或 resolve。数字查询必须保留父块和 registry 语境；不能把任意文本中的同号数字合并为同一实体。

## 频次指标

- StringTable 引用频次适合发现高复用字符串、异常热点和替换影响面。
- Section / tag 内容频次适合发现常见块形、少数异常和近邻样本。
- 高频、低频或高命中都不是安全写入许可。频次统计必须报告分析范围、解析失败和截断。
